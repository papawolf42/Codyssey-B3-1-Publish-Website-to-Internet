# 0012. AWS 크레딧과 무료 사용량 확인

## 질문

이 계정에 무료 크레딧이 남아 있는가?

## 콘솔에서 확인한 결과

2026-10-16 조회 시점, Billing and Cost Management → 크레딧 화면:

- 활성 크레딧: 0개
- 남은 총 금액: US$0.00
- 총 예상 잔여 금액: US$0.00
- 화면 문구: “크레딧 없음 / 사용할 수 있는 크레딧이 없습니다.”
- 사용할 수 있는 활성 크레딧이 없으므로 해당 크레딧의 만료일도 표시되지 않았다.
- 증빙: [0003 크레딧 잔액](captures/0003-aws-credit-balance.png)

금액은 조회 시점의 콘솔 표시다. 화면 안내상 예상 금액은 약 24시간마다 갱신되며 총액은 월별 인보이스 확정 시 갱신된다.

## 크레딧과 프리 티어는 다르다

크레딧은 적용 가능한 사용료를 차감하는 금액이고, 프리 티어는 서비스별 무료 사용 조건·한도다. 크레딧이 없다고 모든 무료 사용 혜택이 없다는 뜻은 아니다.

프리 티어 화면에는 사용 중인 오퍼 1개가 표시되었다. 항목은 AmazonCloudWatch의 월 5 GB-Mo 무료 저장량이며 현재·예상 사용량은 모두 0 GB-Mo였다. 이 화면만으로 EC2가 무료라고 판단할 수는 없다. EC2 실행 전 계정의 적용 조건과 선택할 인스턴스·디스크·공인 IPv4 비용을 별도로 확인한다.

## 실습 전에 확인할 경고

결제 홈의 권장 조치에는 “기한이 지난 결제”로 **KRW ₩7,635, USD $2.72**가 표시되었다. 원화와 달러 항목을 임의로 합산하지 않는다. 연체 발생 시점·상세 청구 내역은 아직 확인하지 않았다.

결제·카드 변경·유료 전환·리소스 생성은 실행하지 않았다. 기존 연체 내역과 실습 예상 비용을 확인하고 사용자 승인을 받은 뒤 리소스를 생성한다.


## 리서치: 탈퇴하고 다시 가입하면 크레딧을 다시 받는가?

### 결론

**탈퇴·재가입으로 신규 고객 크레딧을 다시 받는 방식은 공식 정책상 기대하면 안 된다.** 기준은 단순히 새 계정을 만드는 것이 아니라 신규 AWS 고객인지 여부다. 이메일을 바꾸거나 기존 계정을 닫는다고 신규 고객 자격이 초기화된다는 근거는 없다.

2026-10-16 확인한 AWS Free Tier 약관(표기된 최종 업데이트: 2025-07-09)은 다음을 명시한다.

- 신규 AWS 고객에게 가입 크레딧 US$100 및 활동 완료에 따른 추가 크레딧을 제공한다.
- 한 개를 초과하는 계정에 대해 Free Tier 크레딧을 받을 자격은 없다: “you are not eligible to receive Free Tier Credits for more than one account.”
- 구형 12개월 Free Tier 약관도 추가 혜택을 받으려고 여러 계정을 만들면 혜택 대상에서 제외된다고 명시한다.

이 계정의 최초 가입일과 과거 혜택 수령 이력은 아직 확인하지 않았다. 따라서 잔액이 0인 이유가 만료인지, 소진인지, 애초 미지급인지까지 단정하지 않는다. 다만 이미 AWS 계정을 가진 상태에서 폐쇄·재가입하는 것을 무료 크레딧 확보 수단으로 권하지 않는다. 개별 자격에 이견이 있다면 계정을 닫기 전에 AWS 계정·결제 지원에 확인한다.

### 탈퇴해도 미납금은 사라지지 않는다

AWS 계정 폐쇄 안내에 따르면 폐쇄 전 발생한 요금과 미납 청구에 대한 책임은 남는다. 앞서 확인한 연체 경고를 없애기 위한 방법도 아니다. 계정 폐쇄 시 보통 90일의 폐쇄 후 기간이 있으며, 이후에는 계정을 다시 열 수 없고 남은 콘텐츠·리소스가 삭제된다(일부 예외는 공식 안내 참조).

### 권장 다음 단계

계정은 닫지 않은 채 연체 청구 상세와 실제 과제 수행 비용부터 확인한다. 비용이 부담되면 교육기관이 제공하는 실습 계정·크레딧 등 별도의 정식 지원이 있는지 확인한다. 이런 지원은 자격·제공 여부가 별도이므로 현재 이용 가능하다고 보장하지 않는다. 계정 폐쇄·재가입·결제는 실행하지 않았다.

### 공식 출처

- [AWS Free Tier Terms](https://aws.amazon.com/free/terms/): 신규 고객 및 복수 계정 크레딧 제한, 구형 약관.
- [Close an AWS account](https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-closing.html): 폐쇄 후 미납 책임, 90일 기간 및 데이터 삭제.
