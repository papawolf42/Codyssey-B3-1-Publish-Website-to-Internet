## 크레딧과 프리 티어는 다르다

크레딧은 적용 가능한 사용료를 차감하는 금액이고, 프리 티어는 서비스별 무료 사용 조건·한도다. 크레딧이 없다고 모든 무료 사용 혜택이 없다는 뜻은 아니다.

프리 티어 화면에는 사용 중인 오퍼 1개가 표시되었다. 항목은 AmazonCloudWatch의 월 5 GB-Mo 무료 저장량이며 현재·예상 사용량은 모두 0 GB-Mo였다. 이 화면만으로 EC2가 무료라고 판단할 수는 없다. EC2 실행 전 계정의 적용 조건과 선택할 인스턴스·디스크·공인 IPv4 비용을 별도로 확인한다.

## 실습 전에 확인할 경고

결제 홈의 권장 조치에는 “기한이 지난 결제”로 **KRW ₩7,635, USD $2.72**가 표시되었다. 원화와 달러 항목을 임의로 합산하지 않는다. 연체 발생 시점·상세 청구 내역은 아직 확인하지 않았다.

결제·카드 변경·유료 전환·리소스 생성은 실행하지 않았다. 기존 연체 내역과 실습 예상 비용을 확인하고 사용자 승인을 받은 뒤 리소스를 생성한다.


## 리서치: 탈퇴하고 다시 가입하면 크레딧을 다시 받는가?

### 결론

**탈퇴·재가입으로 신규 고객 크레딧을 다시 받는 방식은 공식 정책상 기대하면 안 된다.** 기준은 단순히 새 계정을 만드는 것이 아니라 신규 AWS 고객인지 여부다. 이메일을 바꾸거나 기존 계정을 닫는다고 신규 고객 자격이 초기화된다는 근거는 없다.

2026-10-16 확인한 AWS Free Tier 약관(표기된 최종 업데이트: 2025-07-09)은 다음을 명시한다.

- 신규 AWS 고객에게 가입 크레딧 US$100 및 활동 완료에 따른 추가 크레딧을 제공한다.
- 한 개를 초과하는 계정에 대해 Free Tier 크레딧을 받을 자격은 없다: “you are not eligible to receive Free Tier Credits for more than one account.”
- 구형 12개월 Free Tier 약관도 추가 혜택을 받으려고 여러 계정을 만들면 혜택 대상에서 제외된다고 명시한다.

이 계정의 최초 가입일과 과거 혜택 수령 이력은 아직 확인하지 않았다. 따라서 잔액이 0인 이유가 만료인지, 소진인지, 애초 미지급인지까지 단정하지 않는다. 다만 이미 AWS 계정을 가진 상태에서 폐쇄·재가입하는 것을 무료 크레딧 확보 수단으로 권하지 않는다. 개별 자격에 이견이 있다면 계정을 닫기 전에 AWS 계정·결제 지원에 확인한다.

### 탈퇴해도 미납금은 사라지지 않는다

AWS 계정 폐쇄 안내에 따르면 폐쇄 전 발생한 요금과 미납 청구에 대한 책임은 남는다. 앞서 확인한 연체 경고를 없애기 위한 방법도 아니다. 계정 폐쇄 시 보통 90일의 폐쇄 후 기간이 있으며, 이후에는 계정을 다시 열 수 없고 남은 콘텐츠·리소스가 삭제된다(일부 예외는 공식 안내 참조).

### 권장 다음 단계

계정은 닫지 않은 채 연체 청구 상세와 실제 과제 수행 비용부터 확인한다. 비용이 부담되면 교육기관이 제공하는 실습 계정·크레딧 등 별도의 정식 지원이 있는지 확인한다. 이런 지원은 자격·제공 여부가 별도이므로 현재 이용 가능하다고 보장하지 않는다. 계정 폐쇄·재가입·결제는 실행하지 않았다.

### 공식 출처

- [AWS Free Tier Terms](https://aws.amazon.com/free/terms/): 신규 고객 및 복수 계정 크레딧 제한, 구형 약관.
- [Close an AWS account](https://docs.aws.amazon.com/accounts/latest/reference/manage-acct-closing.html): 폐쇄 후 미납 책임, 90일 기간 및 데이터 삭제.

## 계정 폐쇄 요청: 최종 확인 대기

사용자 요청으로 계정 메뉴 → 계정 → 계정 해지 확인 창까지 열고, 해지 지침을 펼쳐 확인했다. **계정 ID는 아직 입력하지 않았고 최종 해지는 실행하지 않았다.**

실제 확인 창 안내:

- 폐쇄는 AWS 고객 계약 해지 통지로 간주된다.
- 이번 달 사용료를 포함한 미결제 요금 책임은 남는다. 확인된 연체 잔액은 ₩7,635와 US$2.72이며, 아직 확정되지 않은 사용료까지 모두 포함한다고 보장하지 않는다.
- 예약 인스턴스·Savings Plans는 만료 전까지 청구될 수 있다.
- 90일 이내 계정을 다시 열 수 있으나, 남은 서비스가 재시작되어 요금이 발생할 수 있다.
- 90일 이후 계정은 영구 폐쇄되고 남은 콘텐츠가 삭제되며 미사용 크레딧은 소멸한다.

전체 리전 리소스·백업 필요성·구독·약정 유무는 아직 점검하지 않았다. 최종 실행 전 사용자에게 미납 책임과 데이터 삭제 위험을 알리고 폐쇄 의사를 다시 확인한다. 폐쇄해도 신규 고객 크레딧 자격이 초기화되지 않는다.


## AWS 고객지원에 감면 검토 문의하기

계정 폐쇄는 보류하고 해지 확인 창을 닫았다. AWS 지원 센터를 열었으며, 진행 중인 미해결 사례는 없다고 표시된다. 아직 문의 메시지는 전송하지 않았다.

감면·면제·환불 승인은 AWS의 개별 검토 결과에 달려 있으므로 보장할 수 없다. 현재 미납 상태이므로 우선 청구 금액의 일회성 조정·감면 가능 여부를 요청하고, 이미 납부된 금액이 있는 경우 환불 가능 여부를 구분해서 문의한다.

무료 기간 종료와 잔존 데이터 때문에 청구된 것 같다는 것은 사용자의 추정이다. 무료 기간 종료일, 비용 발생 서비스, 실제 사용 여부, 리소스 삭제 여부는 확인되지 않았다. 따라서 무료 기간이 끝난 뒤 전혀 사용하지 않았다거나 리소스를 모두 정리했다고 단정하지 않는다.

안녕하세요. AWS 계정에서 예상하지 못했던 과거 미납 요금을 확인하여 문의드립니다.

결제 콘솔에는 총 12건의 기한 초과 청구가 있으며, 잔액은 AWS Korea ₩7,635와 AWS Inc. US$2.72입니다. 청구 기간은 2023년 9월부터 2024년 8월까지로 표시됩니다.

과거 서버 이미지를 만들어 보관했던 것으로 기억합니다. 이 이미지와 관련된 저장 데이터가 남아 무료 이용 혜택 종료 이후 비용이 발생한 것은 아닌지 의심하고 있지만, 정확한 이미지 종류와 청구 원인은 아직 확인하지 못했습니다. 무료 혜택과 리소스 보관에 따른 비용을 충분히 이해하지 못해 의도하지 않은 비용이 남았을 가능성이 있어 도움을 부탁드립니다.

다음 사항을 확인해 주실 수 있을까요?

1. 해당 청구의 서비스·리소스별 발생 원인과 무료 이용 혜택 종료와의 관련 여부
2. 현재 추가 요금이 발생할 수 있는 리소스·구독 및 안전한 정리 방법
3. 실수로 발생한 비용에 대해 가능한 범위에서 일회성 청구 조정 또는 감면을 검토해 주실 수 있는지
4. 감면이 어렵거나 먼저 결제가 필요하다면 이후 진행해야 할 절차

필요한 정보나 조치가 있다면 안내 부탁드립니다. 재발을 막기 위해 비용 발생 리소스를 확인하고 정리하고자 합니다. 검토해 주셔서 감사합니다.

### 다음 단계

사용자가 초안을 확인하면 지원 센터의 문제 설명에 전송하고, 필요 시 계정·결제 담당자에게 사례 연결을 요청한다. 감면 승인이나 실제 사례 접수는 접수 확인 화면·사례 번호가 나온 뒤에만 완료로 기록한다.


### 추가 단서: 만들어 둔 서버 이미지

사용자는 이미지를 하나 만들어 둔 것이 원인일 수 있다고 설명했다. 만약 EC2의 EBS 기반 AMI(서버를 복제·복원하기 위한 이미지)라면, 그 이미지의 디스크 데이터를 보관하는 EBS 스냅샷 저장 비용이 남을 수 있다. 서버를 중지하거나 종료해도 별도로 남아 있는 스냅샷의 저장 비용이 자동으로 없어지지는 않는다.

다만 사용자가 말한 이미지가 AMI인지, EBS 스냅샷인지, 다른 종류인지 아직 확인하지 못했다. 현재 리소스와 해당 기간의 청구 항목을 대조하기 전에는 원인으로 확정하지 않는다. AMI 등록 해제만으로 관련 스냅샷이 반드시 함께 삭제되는 것도 아니므로 정리 단계에서는 각각 확인해야 한다. 이미지·스냅샷 삭제는 복원 가능성에 영향을 주므로 별도 승인 없이 실행하지 않는다.

문의 초안에는 이미지 보관 기억을 단서로 반영했으며, 아직 전송하지 않았다.
