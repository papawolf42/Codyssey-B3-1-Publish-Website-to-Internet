# 0010. “Blocked” 상태로 보이는 문서 확인

## 질문

왜 Root와 IAM 차이 문서가 `Blocked`라고 보이는가?

## 지금 확인한 사실

- `docs/0009-root-vs-iam.md` 본문에는 `Blocked` 문구나 상태값이 없다.
- 문서를 만든 직후 Git은 `?? docs/0009-root-vs-iam.md`로 표시했다. Git에서 `??`는 **미추적(untracked)** 파일이라는 뜻이지, 차단(blocked) 상태가 아니다.
- 문서와 첫 캡처는 현재 커밋 `dff4403`에 포함되어 있다.
- Git 자체의 일반 파일 상태에는 `Blocked`라는 상태가 없다.
- AWS 네트워크 확인은 아직 IAM 계정 로그인이 필요해 대기 중이지만, 이는 문서의 상태와 별개다.

## `Blocked`가 실제로 표시된다면

문서 관리 도구나 과제 관리 화면의 `Blocked` 표시는 보통 선행 조건, 권한, 승인, 입력 등이 해결될 때까지 작업을 진행할 수 없다는 의미로 쓰인다. 다만 이 프로젝트에서 어떤 시스템이 표시한 것인지 확인하지 않고는 구체적인 원인을 단정할 수 없다.

## 다음 확인

`Blocked`가 보이는 앱/화면 이름, URL 또는 캡처를 확인한다. 그 위치를 알아야 해당 상태의 원인을 검증할 수 있다.
